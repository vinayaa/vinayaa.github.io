# Vinaya's portfolio

A responsive Angular portfolio starter for a frontend developer job search.

## Run locally

Install dependencies and start the Angular development server:

```bash
npm install
npm start
```

Open `http://localhost:4200/`. Create a production build with `npm run build`.

## Personalize before publishing

- Update the name, introduction, and availability in `src/app/app.component.html`; update the contact email in `src/environments/environment.ts`.
- Replace the starter skills and sample project cards in `src/app/app.component.ts` with your own experience and shipped work.
- Add project videos under `src/assets/projects_videos/` and set each project's `video` path in `src/app/app.component.ts` to display it in Selected Work. More than three videos are automatically shown in a paginated slider.
- Add links to your GitHub, LinkedIn, and resume where appropriate.
- Adjust the page title and description in `src/index.html`.

The sample project cards are visual placeholders, not claims about completed work.
